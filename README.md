## Important verification status

The connector labels documented in this repository are observations and engineering hypotheses, not a confirmed manufacturer schematic. The labels `3CH`, `3CH1`, `3CH2`, `3CH3`, `3`, and `2` must not be assumed to be GPIO, PWM, UART, VCC, or GND without electrical measurement.
